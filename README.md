# The Daily Atlas — Tuesday 17 November 2026

One image that sums up the world news of **Tuesday 17 November 2026**: 33 stories
from six continents on a single front page — numbered, illustrated cards for the
12 biggest stories, a dotted world map with pins matching the numbers, and an
"Also on Tuesday" wire list for the rest. Every story happened or was first
reported on that Tuesday; disputed claims are attributed in the captions.

The image was drawn entirely by code (Python + Pillow): all text is rendered
programmatically and every illustration is an original drawing made of simple
shapes — no photographs and no generated artwork.

`main.py` is the entry program: it copies the bundled `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`), byte for byte,
on every run.
